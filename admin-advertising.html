Stripe Sandbox — Advertising Payment Acceptance

Each category has a dedicated $1.00 Stripe TEST-only price. This is not the real advertising price. Test payments are recorded only in an isolated QA ledger and will never publish an advertisement.

Checking Stripe TEST controls…

Enabling this test mode also enables the existing sitewide Stripe Sandbox switch, which prevents LIVE customer checkout while testing. Turn it OFF when finished. No LIVE payments, advertising invoices, or delivery are activated.
