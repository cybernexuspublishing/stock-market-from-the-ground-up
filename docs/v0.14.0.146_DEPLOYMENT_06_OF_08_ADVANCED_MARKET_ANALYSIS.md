## Security and regulatory boundaries
1. Member-supplied historical/tape CSVs are analyzed **locally** and are not uploaded to central publisher records. Their data authenticity and provider rights are **NOT independently verified**.
2. Tape prints at a quote do not show participant identity, hidden order flow, underlying strategy, quote sequencing or causal buyer/seller intention. 1-second quote matching is a deliberately narrow heuristic, not a verified consolidated-tape reconstruction.
3. Server extracts member ID from Supabase Auth, verifies active member account and existing tool entitlement, queries private Journal by that ID, and omits raw Journal notes, entries and third-party credentials.
4. The 20-observation threshold is a descriptive display safety threshold, **not statistical significance**. Member journal R may be self-reported, selected, inconsistent or missing.
5. No change to paid product catalog, canonical 419 Labs/94 Foundations IDs, Owner-approved pricing, Stripe LIVE locks, KDP exclusivity, lesson text or actual database policy.
6. Existing `v0.14.0.110_ADVANCED_WORKSPACE_ENTITLEMENT_LOCKDOWN_OWNER_REVIEW_REQUIRED.sql` must be confirmed installed before production private-workspace signoff. This deployment does NOT rerun that migration.
7. Cloudflare secrets remain server-only; no API token, sample credentials, provider data archive or extra paid feed is bundled.
