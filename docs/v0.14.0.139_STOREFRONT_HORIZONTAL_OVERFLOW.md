The prior v138r1 removed an obsolete replay card injector; it does not prove the detail-page overflow was fixed. See Issue #103.

## Technical correction

Add explicit min-width:0 / max-width:100% constraints to nested product detail grid/flex containers, wrapping of long URLs / unbroken identifiers, responsive image/media limits, and pre/code wrapping. Preserve actual content and focusable UI. **Do not hide overflow** with `overflow-x:hidden`; the existing test will still detect real oversized document width. Keep the DOM/card layout, pricing, book metadata, KDP restrictions, checkout URLs, historical lesson material, Labs and signed webhook unchanged.
