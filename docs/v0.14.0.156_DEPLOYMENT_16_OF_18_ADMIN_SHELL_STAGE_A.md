## Inspected source
The current `admin.html` imports 22 distinct script paths (14 have names beginning with `admin-` or `admin.js`, some using query versions). It has 10 static core `data-panel` buttons and one explicit `admin-navigation.js` script. A single explicit import is not proof that the runtime has no duplicate observer, re-mount or event-handler behavior.

The existing `assets/js/admin-navigation.js` remains the single sidebar presentation owner (previous v0.14.0.9 stabilization). It still classifies some modules using button-label regular expressions, contrary to the final D16 stable-ID registry requirement. The core `admin.js` also retains its independently handled panel routes. Many other installed scripts create dynamic panels and module controls; removing them without a dependency test may reproduce earlier Admin failures.
