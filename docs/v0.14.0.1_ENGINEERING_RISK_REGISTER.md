## Severity and evidence methodology

**CONFIRMED (SOURCE)** denotes a condition established by exact uploaded source logic, *not* exploitation in the hosted system. **POTENTIAL / UNVERIFIED** means the condition depends on deployment grants, configuration, real provider behavior or live data not available in this audit. **LOCAL PATCHED** means a candidate code change has been made and local tests passed, but migration and production acceptance remain outstanding. No live credentials, production data, provider webhook events or real-user sessions were used.

## Decisions and constraints preserved

- No source patch here grants a real subscription, Lifetime plan, book key or tool pass to synthetic accounts.

- Member payment entitlements are not automatically revoked by marketing visibility controls.
- Founding prices remain **draft** $49.99/month and $499/year, hidden/inactive, with no provider checkout.
- Preserve historical Lab IDs and the approved v1.14 Foundation manuscripts; the site does not become a downloadable public edition of the books.
- Each supervised historical trading example distinguishes documented observation, model assumption and hypothetical execution. Instructional examples do not constitute market observations.
- New security work must preserve compatibility with the Admin Control Center and its separate Grant Web Solutions draft administration, without asserting it is an operational site builder.
