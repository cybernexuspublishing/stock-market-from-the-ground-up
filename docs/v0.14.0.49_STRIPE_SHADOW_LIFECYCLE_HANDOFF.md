## Engineering scope

v0.14.0.49 introduces a second mandatory guard on the Stripe TEST webhook. Previously, having `GU39_SANDBOX_SHADOW_GATE=true` with valid encrypted secrets allowed signed test webhook events to reach `gu39_shadow_apply` even if the Owner had switched off testing in the database. Now the endpoint checks `gu39_sandbox_settings.enabled=true` before Stripe API access or the isolated ledger write. A false/missing/unavailable Owner switch **fails closed**. Existing Stripe HMAC validation against the exact request body, test-only check, and isolated service-role RPC remain in place. Stripe Connect events naming a different account are rejected.
