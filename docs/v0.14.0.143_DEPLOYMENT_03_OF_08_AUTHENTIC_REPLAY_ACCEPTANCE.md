## Critical architecture correction

The v0.14.0.97 migration previously generated 419 fictional OHLCV scenarios and could mark them `published`. This conflicts with the newer controlling Owner decision that learning and teaching must not present invented stock-market observations. Its SQL and existing data are preserved solely as *historical migration/records*, **not executed again or deleted**; already saved member progress and Lab IDs remain intact.

The current member `functions/api/learning-replay-v01492.js` now **denies all original_synthetic market observations**, even when an older record is tagged `published`. No unverified entry appears in the replay catalog, can start a session, or can continue a previously opened session after revocation. An empty approved source catalog is an accurate status, never a cue to fabricate market values.

- Existing `MARKET_SIMULATOR` access may view an explicitly approved authentic historical dataset.
- Lower-tier `ONDEMAND_TRAINING` does **not** acquire `MARKET_SIMULATOR` access. It may view only approved authentic sources with a separate `ondemand_training_approved: true` decision from the Owner. Synthetic market observations are not a substitute for the paid entitlement.
- The current server-owned sequential first-bar decision, atomic replay advancement, member isolation, and private Journal integration are retained. Hypothetical order fills remain **modeled estimates** and must not be described as executions.

## Mandatory historical dataset metadata / source review

A source is eligible for the existing authenticated member Replay only when ALL checks succeed:

`market_datasets.status='published'`, `dataset_type='ohlcv'`, nonempty source attribution/license note, valid ticker, `metadata.real_market_security=true`, `historical_evidence_verified=true`, `evidence_verified=true`, `licensed_for_member_display=true`, nonempty and policy-complete corporate-action review, `trading_conditions_reviewed=true`, `packet_integrity_reviewed=true`, `corporate_actions_reviewed=true`, `license_publication_reviewed=true`, valid source-date, SHA-256, provenance, and signed/dated review fields. For IEX, `venue_scope` must be `IEX_SINGLE_VENUE`. An Owner checkbox by itself is not independent authenticity evidence.

The Owner Lab auditor uses this same source verifier. Historical envelope review, actual private lesson quality, topic-specific reviewed rubrics, 419 Lab mappings and 30 competencies remain independent acceptance gates; **zero Labs are automatically certified**.
