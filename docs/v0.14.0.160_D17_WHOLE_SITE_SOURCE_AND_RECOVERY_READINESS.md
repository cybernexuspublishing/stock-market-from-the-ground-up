## Critical unresolved defects that must be corrected in the active application before release
- **Support opaque Supabase key:** `functions/api/support.js` still sets an opaque `sb_secret_...` as a Bearer JWT; use only an API-key header for that modern key, while preserving legacy JWT role behavior.
- **Support request size:** Support create/reply/reopen currently calls unbounded `request.json()`; enforce a strict real-byte limit before parsing.
- **Support reopen ownership:** `action=reopen` updates the user's filtered ticket but does not first independently confirm a matching owned, eligible closed/resolved record; prevent false success and any unauthorized state transition.
- **Admin member inspection crash:** `assets/js/admin-unified-preview-v014156.mjs` references `data.users` from `inspectMember` where `data` is not in scope; move the Inspect control creation to the row-list rendering function and keep detail rows free of that reference.
- Two attempted changes to the active Support/Admin code were blocked by GitHub tool safety checks. Do **not** claim they were applied or attempt an unreviewed bypass. A new source checker is not a substitute for correcting active handlers.
