# v0.14.0.8 — Admin Control Center Navigation & Dashboard Repairs

**Source baseline:** User-confirmed production v0.14.0.7 source package. **Status:** source-verified release candidate, not deployed or production-accepted by assistant. **Scope:** Admin UI/navigation and display-version correctness; no database schema changes.

## Root causes verified from source

1. `assets/js/layout-integrity.js` unconditionally overwrote the release badge with `v0.13.5.7.6`, including on newer deployments. The old badge was not proof that the website had rolled back.
2. `assets/js/production-completion.js` rebuilt the sidebar from a fixed list and discarded unrelated buttons **and anchor links**. This hid Account Management, Control Center Directory, Grant Web Solutions, plan controls, training editor, and several later modules depending on initialization timing.
3. `assets/js/admin.js` rendered all eight dashboard counters as non-interactive `<div>` cards. The Open Reports count had no route into report management.
4. Original forum reports are listed by the existing Admin `community` panel using `/api/admin?action=forum`. The separate `commons_mod_queue` currently covers Market Commons reports whose `content_id` is prefixed `commons:`. Those are distinct but related screens; routing the combined dashboard count exclusively to the modern-only queue would be incorrect.

## Implemented corrections

- `admin.js` renders eight accessible button counters. They go to the authorized, existing account, commerce, catalog, content, and all-reports panels. The Priority checks item for open reports is also clickable. No new authorization is granted.
- A dedicated **Reports — All Member Reports** shortcut now links to the existing Admin community report list (which reads the shared `forum_reports` table). A separate **Market Commons — Moderation Queue** shortcut is shown only when the `forum.moderate` permission is present and its UI module is installed.
- `admin-navigation.js` recategorizes **existing controls**, including late-mounted buttons and internal links, into coherent functional groups. Unknown installed modules remain visible in **Additional Installed Controls**; hidden/disabled controls remain restricted. The stable filename is intentionally unversioned.
- `production-completion.js` no longer destroys links or buttons that were not in its initial fixed group list.
- Release version badge reads the `application-version` metadata emitted from Cloudflare middleware, instead of hard-coded legacy values. All source version strings tied to frontend badge rendering are updated. Service worker cache namespace incremented to `groundup-v01408-public`.
- Admin sidebar groups contain real existing frontend modules only. This change does not pretend that unfinished backend services are complete.
