## Critical correction

The v0.14.0.61 staging webhook retained `ident(...,'cs_live')` checks in the session validation path. A successful Stripe TEST checkout provides `cs_test_...` identifiers, so the earlier handler rejected valid TEST sessions before entitlement fulfillment. This is a genuine integration defect, not a configuration issue. v0.14.0.62 changes all staging-specific session checks to `cs_test`. The staging checkout response now unambiguously declares TEST mode (`sandboxOnly:true`, `live:false`) rather than incorrectly claiming LIVE Checkout. No LIVE code, production database or approved product pricing is modified.
