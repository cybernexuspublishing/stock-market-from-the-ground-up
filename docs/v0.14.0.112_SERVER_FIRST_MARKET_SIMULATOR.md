## User-facing architecture

`simulator.html` now opens with **server-controlled replay as the default mode**, using the *existing* independently implemented and tested `/api/learning-replay-v01492` backend and `assets/js/verified-replay-v01492.js` frontend. The page embeds the full original and rights-verified replay experience, including published eligible dataset discovery, durable member session resume, earliest bar observation, optional source-grounded first decision, and server-serialized forward-only cursor.

The old CSV and connected-data browser simulator is not deleted or covertly renamed. It appears only if the member explicitly selects **User CSV / Browser Practice**. Its initialization is deferred and a running client playback timer is paused when returning to the secure mode. The legacy engine still has inspectable arrays and **current-candle-close entries/exits**. It is therefore not a gradeable historical replay or independently verifiable actual market execution. The distinction is labeled.

## Execution assumptions

The server replay uses `functions/_lib/replay-engine-v01492.js`. Order side/type/size remain enforced by the backend. The integrated replay workbench additionally allows actual user entry of adverse slippage basis points, bid–ask spread basis points and estimated dollar fees; the browser validates bounded values and the server independently validates those exact ranges. The modeled order may estimate a fill on the NEXT revealed bar; OHLCV intrabar path is unknowable and total bar volume is not accessible order-book depth. No invented fill/position/P&L/competency mastery is written to the Journal.

`verified-replay.html` remains a supported standalone entry point sharing precisely the same source and accessible controls. Both embedded and standalone interfaces use plain-text output for model estimates and explicitly classify untriggered/low-volume orders as *no confirmed fill*.

The only private Market Replay access remains in the server API, including `MARKET_SIMULATOR` and the narrower OnDemand entitlement (fictional GUSIM only). Browser CSV retains its existing `MARKET_SIMULATOR` access check. The canonical Market Simulator does not copy unrevealed server candles or private session IDs into localStorage.
