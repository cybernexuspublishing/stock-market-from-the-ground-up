## Source defect identified and addressed
The v0.14.0.58 Checkout source checked `r.checkout_enabled` for **both** plan and tool rows. The installed canonical `public.platform_tools` definition has no such column, while `public.platform_plans` does. Consequently the original condition would prevent all four tool purchases even when the tool was active, public and live. The v0.14.0.59 code now checks plan `checkout_enabled` only for plans and tool `status='live'` for tools, while continuing to enforce active, public visibility, website-wide commerce lock, verified LIVE price and independent Owner launch controls. The existing mocked Stripe integration now includes a tool checkout without an artificial `checkout_enabled` field.
