## Defect corrected

The v118 review queue locked a pre-reveal reflection but afterwards showed only `actual_exit`, `net_pnl`, etc. For educational server replays, these are intentionally blank. Consequently a learner could not compare a locked first observation to the observed subsequent OHLCV evidence in the three spaced reviews. It was not a substantive replay review.

The v119 route adds `GET /api/journal-replay-review-v014118?action=evidence&reviewId=<id>`. It checks the authenticated account and existing entitlement; verifies the user's locked AND revealed review stage, replay-Journal link, finished server session, published source and usage rights, then returns at most 40 candles ending at the server's recorded cursor. Future data beyond that cursor are never selected. Revoked market-source display is denied, including after a review had previously been revealed. The client displays the bounded observed candle sequence and fictional-versus-historical provenance beside the existing outcome panel, without creating a simulated broker fill, competency grade, stock price or P&L.

## Security / data boundary

Review ID and session ID are never authorization credentials. Every private REST read is scoped to the authenticated member. Server rights are checked again on every evidence request. An outcome-hidden note is required BEFORE the reveal transition; existing v118 SQL remains authoritative. The browser cannot choose a bar index, dataset code, or query future data. Evidence is not cached. Previously linked evidence remains private.

## Deployment and acceptance

No new SQL or Cloudflare environment variable is required **after v118 has been installed**. The existing `GU_REPLAY_JOURNAL_V01494_ENABLED` integration flag still requires actual owner-reviewed SQL installation and role/rollback tests. To verify, sign in to two separate accounts, complete a replay with at least two bars, allow a review stage to become due, assert direct evidence GET is denied before reveal, lock original analysis, reveal, confirm limited bars, then complete a post-reveal comparison. Verify right revocation hides data. Source-level mocks are not production tests. Independently validate screen-reader table navigation and narrow-screen scroll.
