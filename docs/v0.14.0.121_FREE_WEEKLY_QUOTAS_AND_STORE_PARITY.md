## Business rule

FREE gets **15 newly created Journal records per UTC ISO calendar week (Monday 00:00 UTC reset)**, and **10 newly saved browser/CSV simulator exercises per week**, counted within the 15 Journal records. Entitlement to the private server-controlled Market Simulator, original replay sessions and historical licensed OHLCV is **not included in FREE**. This avoids misleading the public into believing a browser-only simulator save grants paid historical replay access. Delete/recreate does not refund recorded usage. A separate paid Journal & Analytics entitlement exempts Journal record quota; a Market Simulator entitlement exempts the simulator-save quota. Existing Stripe products, prices, entitlements, trial Book Keys and books remain unchanged.

## Existing defects repaired

* Original v0.11 Journal limit said "10 per month" but SQL counted **all lifetime Journal records**, so a free learner at 10 was blocked permanently.
* Original trigger counted three monthly simulator-source-tagged records with no concurrency lock; simultaneous submissions could exceed the cap. A user could delete records and recreate to evade a live-record count.
* A free user could attach simulator_source after creation to evade a careless new-record-only limit. New triggers enforce initial save **and** the NULL-to-non-NULL update.
* Store rendered generic free benefits and a misleading Tutor preview promise although the free entitlement does not authorize Market Tutor API usage.
* Store card, standalone detail page, and alternate membership renderer differed. Monthly plan should be named **Full Platform — Monthly** at $69.99; source configuration incorrectly said ad-free while plan policy showed limited sponsorship.
* Server replay remains a distinct, paid, source-rights-reviewed feature. Never imply 10 free server replay sessions.

6. The quota is a per-account creation/use policy, not a cap on opening the browser simulator without saving. An unsaved CSV in memory is not a durable session and cannot be reliably counted by the server.

## Security notes

The `gu_free_weekly_usage_v014121` table is service-private; member visibility comes solely from `gu_v014121_my_free_week_usage()` using `auth.uid()`, never client-supplied user IDs. The per-user advisory xact lock enforces concurrent requests. A one-way weekly count avoids deletion/recreate reset. The function reads limits from `platform_plans.metadata`, the same data that drives Store claims. The RPC is private account-scoped and cannot modify usage.
