## Commercial AI product and ownership

The company operates **its own first-party paid AI educational SERVICE**, sold under its existing MARKET_TUTOR tool entitlement and included in the applicable platform membership. We build and control the user experience, prompts, educational subject matter, private access control, content retrieval, learning workflows, consent, usage caps, feedback and product pricing. Model inference is supplied by a separately contracted third-party provider and billed to the company unless and until we build/deploy our own trained model. It is inaccurate to market an API-integrated model as company-owned foundation model weights. No new Stripe SKU, second Supabase project, automatic purchase flag or checkout override is created by this phase.

**Existing platform SKU:** MARKET_TUTOR, previously one of four separately priced principal tools (existing approved $29.99/mo tool category; live fulfillment and account entitlements must be independently checked). The schema must be confirmed usable by the server and inaccessible to member clients. Runtime uses the existing `SUPABASE_URL` / publishable / service credentials; does not create a second database.

**Critical economics:** A request-count ceiling does NOT constitute a monetary billing ceiling. Provider prices and token usage differ by model; some API providers charge for unsuccessful/aborted requests. Configure independent provider usage caps/alerts and verify unit economics before funding/opening a paid AI service. Output tokens are bounded to 350, input is bounded by validated request sizes, but billable tokens can vary. The ledger intentionally counts reserved provider attempts (even when the provider fails) to prevent abuse; it is NOT an invoice or guaranteed cost record.
