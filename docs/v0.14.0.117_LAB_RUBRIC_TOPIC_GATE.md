## Discovered quality defect

419 Lab rubric drafts are generated from four generic question patterns rather than 419 individually authored assessments. An original v96 numeric example can be mechanically correct but irrelevant to the actual Lab. Actual SQL chooses one of nine arithmetic families by simple title/skill-group precedence; no semantic educator signoff is derived from that classifier.

Concrete contradictions include the “ETF Versus Index” Lab receiving generic range math, Reading the Tape Labs receiving a sum of three printed trade sizes, and the “Construct a Down / Bearish Candle” Lab receiving a generic upward candle in the v96 CANDLE family.

**Source verified:** `supabase/migrations/v0.14.0.96_419_ORIGINAL_CONCEPTUAL_ASSESSMENT_DRAFTS_OWNER_REVIEW_REQUIRED.sql`, `lab-catalog.json`.

## Engineering corrections

Owner `POST /api/training-editor?action=review` now rejects unamended v96-origin seed templates. Before approval, it requires at least one newly authored application question with a new ID, prompt length >=80, and teaching explanation >=120; the existing private keyed-answer validator still applies. This is a minimum **procedural** check, never proof of substantive learning quality. Existing reviewed versions and student records are not modified. Other authored sources remain on existing review requirements.

Training Editor presents an explicit v96 topical warning when loading a rubric. No new DB schema, product, tool entitlement, Lab ID, price or public answer-key exposure is introduced.
