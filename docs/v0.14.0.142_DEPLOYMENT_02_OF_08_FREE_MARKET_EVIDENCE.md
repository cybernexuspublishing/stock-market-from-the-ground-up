## Research / permitted-source verification

- **IEX equities HIST:** IEX advertises **free T+1 historical file downloads** with a trailing ~12-months download window. Data are IEX-only; TOPS covers venue top-of-book and last sales, with DEEP/depth files separate. Files are compressed binary PCAP; they are **not** a currently supported, general free REST market-data API. The old IEX public API was retired in 2021. Source: https://www.iex.io/products/equities/market-data-connectivity and https://iextrading.com/trading/market-data/.
- **Rights:** https://www.iex.io/legal/hist-data-terms specifically addresses distributing, selling, furnishing or providing access to IEX historical data, conditioned on precise attribution and its other requirements. IEX retains ownership, disclaims accuracy, and emphasizes that historical information does not reflect other U.S. markets. This is a promising free source **not a completed legal/publication sign-off** for ebooks, full member downloads or client APIs.
- **SEC EDGAR:** https://www.sec.gov/search-filings/edgar-application-programming-interfaces confirms public submissions and XBRL JSON without an API key or login. https://www.sec.gov/about/developer-resources and https://www.sec.gov/about/webmaster-frequently-asked-questions require fair access (currently max 10 requests/sec combined), declared organization/contact User-Agent, and efficient access. Government-created and public filing data are generally reusable; particular third-party attachments require separate rights.
- We will **not** create multiple accounts to bypass provider quotas, describe IEX-only trades as SIP consolidated prices/volumes, repackage third-party charts without permission, invent quotations, or assume synthetic protocol fixtures are market-history evidence.

## Implemented in this phase

1. Existing protected `GET /api/owner-roadmap?action=delivery-summary` returns a nonsecret static source-status register **after the same Owner authorization**. The existing Admin delivery panel renders current IEX/SEC status, no duplicated Administration, catalog, roadmap, standalone product or market-data keys.
2. The first-party offline `scripts/market-data/iex_tops.py` streams local authentic IEX TOPS 1.6 classic PCAP (including `.gz`), extracts only selected venue Trade Report messages, filters a specified ticker/session/date, sorts by timestamp, calculates 1/5-minute venue OHLCV with four-decimal integer price arithmetic, and computes a source-file SHA-256. Each output carries mandatory provenance, IEX attribution, explicit data limitations and **quarantined / not member-approved** flags.
3. `scripts/market-data/sec_edgar.py` obtains one specified CIK from SEC's fixed public HTTPS host with a real declared business User-Agent, bounds JSON size, verifies returned CIK/shape, creates a private quarantined review file; no API key or third-party account needed.
4. GitHub CI unit tests use **synthetic network/protocol fixtures strictly for software verification**, never member instruction, lessons, trades or historical displays. There is no real copyrighted market content, fake live quotes, secret or unrestricted public API in GitHub.

## CLI use, no cloud bill

Download a **genuine** TOPS 1.6 daily capture from IEX (if the current service still supplies that feed version), keep it outside this repository and run on the Owner's computer. Example usage illustrates command syntax only; it does not assert that a specific file was downloaded.

```powershell
python scripts/market-data/iex_tops.py --file "C:\market-evidence\raw\20261007_IEXTP1_TOPS1.6.pcap.gz" --symbol AAPL --date 2026-10-07 --interval-seconds 60 --output "C:\market-evidence\review\AAPL-2026-10-07-iex-review.json"
```

For SEC, supply an actual controlled organizational contact (below is a placeholder to be replaced):

```powershell
$env:SEC_USER_AGENT="Cyber Nexus Research real-contact@your-actual-domain.com"
python scripts/market-data/sec_edgar.py --cik 320193 --output "C:\market-evidence\review\sec-320193.json"
```

Python 3.9+ stdlib; Windows tzdata may require availability of the IANA America/New_York timezone database. No SEC API key or IEX historical REST key exists to configure in these scripts. The historical file may be several gigabytes; do not decompress in Cloudflare Workers or upload raw PCAP to Supabase/GitHub.
