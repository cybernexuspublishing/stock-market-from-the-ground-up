**Project:** The Stock Market: From the Ground Up

**Status:** SOURCE CORRECTION COMMITTED; FULL 419-LAB GRADING/COMPETENCY INTEGRATION AND PRODUCTION ACCEPTANCE STILL OPEN.

## Verified issue
The original `assets/js/interactive-training.js` kept one shared mutable `labId`, `mode`, `attemptId` and `mount` for asynchronous `available`, `start`, `answer` and `resume` calls. The existing `assets/js/lab-player.js` could immediately rebuild the workspace when a student switched a Lab mode. Pending requests could later render into the new workspace, show stale feedback, or reveal the previous mode's unverified completion state.

## Engineering change
- Introduced an incrementing client-side UI generation token and a public `cancel()` method on the **existing** first-party interactive training object. No second training application was created.
- Lab player calls `cancel()` on mode rerender. `begin()` and both student-answer/continue paths ignore responses that belong to a prior generation or disconnected target mount.
- Old error callbacks are likewise ignored after a mode switch, so errors from old requests do not overwrite the new lesson status.
- The Lab player's post-`begin()` fallback notices check the original Lab ID, mode and assessment slot before changing the current UI.
- Existing POST `expectedStep`, server-authoritative grading, private rubrics and secure session-bound member API remain intact. No extra retries, grades, entitlements, credentials or network providers introduced.
- Source syntax check performed directly for both JavaScript modules; full asynchronous browser race verification remains **DEFERRED TO D18** per Owner instruction.
- Added `tests/test_v014153_training_stale_mode.mjs` to the established curriculum workflow and shared source verifier.

## Limitations and D13 remaining
This closes only one stale-client-rendering risk; it does **not** certify graded correctness, cross-account Supabase RLS, all 419 topic-specific rubrics, 30 competency assessment dimensions, remediation, historical-no-lookahead testing, feedback, full accessibility or editorial approval.
