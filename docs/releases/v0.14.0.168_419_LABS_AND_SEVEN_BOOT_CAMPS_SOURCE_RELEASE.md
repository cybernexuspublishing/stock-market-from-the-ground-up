## Delivered source changes

1. **419 individually keyed instructional study bridges** — `data/lab-teaching-bridges-v014168.json` contains one five-focus public lesson for each canonical Lab ID. Each inherits its existing source title and one or more of the 30 established competency guides, with separate Understand, Recognize, Apply, Common Mistake and Limitations. These **study bridges are provisional**, not evidence that 419 full historical/assessment/editorial acceptance reviews passed. The exact known canonical IDs are validated at load.
2. **Step-by-step formula instruction** — `assets/js/lab-v34-interactive-lessons.js` retains the approved detailed bullish/bearish candle lessons. It adds explicitly simulated formula-first cases where applicable for VWAP, EMA, relative volume, risk per share, sizing, reward-to-risk, quoted spread/slippage, turnover, MFE/MAE and Level II quotes. Verified historical market prints are not invented.
3. **Shared instructor and curriculum load** — `assets/js/lab-engine-v32-universal.js` now validates all 419 records and passes the correct Lab teaching guide. `assets/js/lab-v33-instructor.js` uses that guide or the current Boot Camp day's own content when a learner opens its five tabs. The existing nine-stage Learning Journey is unchanged: Start, Learn, Experiment, Predict, Practice, Assess, Review, Transfer, Results.
4. **All seven Academy program identities** — `functions/_lib/bootcamp-academy-v014168.js` preserves:
   - 5-day *The Truth Behind the Ticker*
   - 7-day *Build Your Own Stock Watchlist*
   - 10-day *Mastering Stock Scanners*
   - 30-day *The Complete Trading Foundations Boot Camp* (existing approved 30-day source, unchanged)
   - 45-day *Chart Reading and Trading Setups*
   - 60-day *Risk, Execution, and Trading Discipline*
   - 90-day *Advanced Simulated Trading Practicum*
5. **247 program-day positions** — The six new programs have their own day objectives, practice instructions, progression labels, source-day anchors, related existing Labs, limitations and official competency references. For the 45/60/90-day paths the three instruction/rehearsal/transfer cycles are an **original editorially provisional development sequence**, not six owner-accepted finished training manuals or individually accepted graded assessments.
6. **Member-facing Academy** — `bootcamp-academy.html`, `assets/css/bootcamp-academy-v014168.css` and `assets/js/bootcamp-academy-v014168.js` add responsive program browsing and member day navigation, enrollment, private reflections, related original Labs, and shared Talia instruction. The Learning System and controlling 30-day page now link to the Academy.
7. **Authoritative progress boundary** — `functions/api/bootcamp-academy.js` requires the existing `ONDEMAND_TRAINING` entitlement for private program operations; the original 30-day API remains authoritative for its progress. Server actions validate same-origin writes, program version, exact day range, known revision and authenticated member identity. Completing a day/using a Spark cannot grant a Lab grade or mastery.
8. **New SQL migration (manual review/application required)** — `supabase/migrations/v0.14.0.168_BOOTCAMP_ACADEMY_OWNER_REVIEW_REQUIRED.sql` adds six-course enrollment and versioned day-progress tables with RLS, no PUBLIC/anon/authenticated table privileges, service-role-only writes, serialized writes and optimistic revision checks. It is additive; it does not overwrite the installed .144, .163 or .164 migrations or any financial data.
9. **Read-only database acceptance** — `supabase/admin/v0.14.0.168_ACADEMY_SEVEN_PROGRAMS_POSTFLIGHT_READ_ONLY.sql` reports table presence, RLS, role privileges and RPC execution permissions. It does not prove member API acceptance or modify data.
10. **Build and tests** — The Cloudflare Pages build copies the individual Lab instructional JSON and Academy assets. Tests now cover 419 IDs, 30 competencies, seven titles/durations, all 247 program day positions, original 30-day preservation, formula examples, no client-side grading, and mobile/desktop Academy enrollment/account-switch Playwright fixtures.
