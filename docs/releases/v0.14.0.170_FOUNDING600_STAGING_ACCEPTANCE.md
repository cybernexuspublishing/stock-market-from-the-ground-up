## Critical missing integrations — NO-GO

1. **Supabase owner-access required:** Read-only live schema preflight, database backup, compatible additive migration, RLS/privilege verification, PostgreSQL advisory-lock seat concurrency, paid-cycle renewal and restricted-account tests. No Supabase transaction has been executed.
2. **Capacity before Stripe charge:** Candidate .169 currently assigns the founding number *after* a paid invoice. Real 600th/601st overlapping checkouts could charge an unfillable customer. A pre-payment reservation lifecycle reconciled to Stripe Checkout expiration is mandatory.
3. **Subscription billing:** GU58 live checkout explicitly validates eight SKUs and does not provide Founding plans/Sparks packages. Signatures, owned checkout session, renewal, proration, dunning, refund, cancellation and grant events must be integrated without bypassing the eight-product guard.
4. **Crownlight Sparks commercial issuance:** Source store checkout disabled. Ledger billing grants, Stripe pack purchases, origin-key idempotency, refund reversal, expiry migration, security and fairness checks remain.
5. **Six benefit end-to-end flows:** The guard module is **only input-validation logic**. Member UI, authenticated APIs, persistence, issuance, access and audit are not fully integrated. The existing site-announcements and Market Commons infrastructure should be extended, not duplicated.
6. **Compliance and accessibility:** Final recurring consent language, cancellation path, account lifetime terms, real-source permissions, responsive keyboard and axe-core WCAG testing remain.
7. **Site content:** The 419 Labs and seven Boot Camp program catalog have additional documented editorial and production acceptance requirements; no working on-site simulated-trading execution is included.

## Discovered blocker and mitigation

The v0.14.0.169 candidate SQL tests `enrollment_enabled` at the start of the paid-cycle function, which also blocks renewals when enrollment closes. The local v0.14.0.170 core candidate moves that check to **new founder assignment only**, preserving existing subscriber renewal processing. This change requires actual PostgreSQL validation.

## Production safeguards

- Never merge to `main`, enable new checkout or change Stripe LIVE without fulfilling all P0 items.
- Never automatically change a founder subscription into the regular $69.99 plan at public launch.
- Founder identities are permanent and nonrecyclable; no free trading execution claims.
- Existing $69.99/$699/$2499/$19.99/$29.99 public price catalog stays unchanged.
- Existing `checkoutEnabled=false` and disabled launch gates stay closed.
