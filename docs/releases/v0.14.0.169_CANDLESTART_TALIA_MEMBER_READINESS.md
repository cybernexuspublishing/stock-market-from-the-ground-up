## Scoped source implementation

1. Start (stage 0) now introduces the outcomes in conversational language, before calculations or quiz questions. Candlestick Start contains a responsive candle **schematic, not a market-data record**, and three visual goals. The member's historical setup still comes through the existing instructor header and is not confused with the schematic.
2. Learn preserves the accepted nine stages (Start, Learn, Experiment, Predict, Practice, Assess, Review, Transfer, Results), and does not substitute the alternate READ/OBSERVE/DECIDE labels from research drafts. Talia uses her normal instructor greeting instead of narrating competency boilerplate.
3. Talia's displayed lesson heading is semantic h3 markup, not the first unstyled line of the typewriter paragraph.
4. The full-candle teaching highlight now offers Previous/Next teaching step, with nine successive narrated steps. Navigation is educational only; it cannot submit grades, spend Crownlight Sparks or unlock protected replay/Assess.
5. Bullish/bearish formula demonstrations explain the reasoning **between the named formula and the substituted prices**, including body, range, upper/lower wick, arithmetic check and body percentage. No claim about the temporal order of a candle's high and low is added.
6. The five original tabs retain distinct authored content (Understand, Recognize, Apply, Common mistake, Limitations).
7. Regression coverage was added to `tests/test_v014167_talia_five_candle_tabs.mjs`, wired into `.github/workflows/learning-tutor-v01492.yml`.
8. An old Market Tutor regression expected every submitted question to uncheck the member's AI preference. The source preserves the owner's approved Profile preference and still sends an explicit `allowModel` boolean on each request. The stale test expectation was corrected without enabling inference, spending quotas or changing external providers.
