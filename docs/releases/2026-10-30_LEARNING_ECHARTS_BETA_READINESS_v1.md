## Approved beta operating boundaries

1. The same quality of introductory instruction, worked explanations, corrective feedback, alternative instruction and unlimited formative retries must be available to every learner with access to the lesson. No Lumens are required for teaching.
2. Crownlight Lumens remains the single member currency. No new wallets, credits, prices or expiration logic are introduced here. Revenue-bearing checkout is not involved in this acceptance.
3. The original protected assessment service owns graded attempts, private answers, integrity checks and official mastery. Formative ECharts worksheets must not award mastery.
4. All additional chart examples in the ECharts learning workstation are explicitly FICTIONAL, not actual session history or unrevealed replay data. Historical evidence requires separate provenance and licensing acceptance.
5. The Chart Studio UI has four choices: Standard, ECharts, Advanced and Professional. The existing server access rules remain controlling. ECharts is a visualization choice under Standard-level entitlement, not a new independently priced premium grade.
6. Free members retain the 15-new-Journal-records/week and 10-saved-simulator-exercises/week limits; learning explanations and retries are not counted as those records.
7. Only the existing GitHub main branch is used. No paid service subscriptions, live charges or new production user identities are authorized by this acceptance.

## Verification program

**Structural source audit:** Every canonical Lab must have the correct one-to-one teaching bridge, five distinct instructional facets, a valid existing competency mapping and no mistaken assertion of historical data or independently graded results. Each of seven Academy program curricula (247 study days in total) and the five Free Foundations days must preserve an authored lesson, observable objective, practice, limits and any linked canonical Labs. Produce a complete JSON report with flagged content for individual editorial review.

**Interactive browser test:** At 390, 768 and 1440 px, verify ECharts renders the candle and VWAP cases, displays an accessible OHLC/trade table, supports keyboard-accessible controls, clears stale answers when data change, gives calculation-specific remediation and permits unlimited practice. The test must execute against local build assets without authenticating a real user.

**Studio / security tests:** Test the existing Standard/ECharts/Advanced/Professional menu with server-verified entitlements and no privilege bypass. Preserve immediate clearing on sign-out, account switch, expired access or revoked grants. Historical replay must remain server-revealed and source-scoped.

**Curriculum browser checks:** Retain all existing canonical Lab and Boot Camp tests, including the existing annotated chart controls, introductory Talia teaching, independent-stage concealment, member-owned progress checkpoints, responsive widths and account-switch isolation.

**Authenticated release tests (beta session):** Sign in separately with a Free baseline identity and permitted Founding-level/QA test identities, verify each Studio level, server progress save/restore, private assessment and Lumens balance, and record actual Cloudflare deployed SHA. No customer billing or credential fabrication is permitted. A missing QA credential is **not** proof that the experience passed.

## Acceptance and limitations

A green source/fixture audit supports **beta-test readiness of the integrated instructional system**; it does not certify all individual lessons as independently editorially approved, verify access using real paid accounts, publish all 419 Labs for all tiers, or establish that licensed historical replay is universally available.

Individual curriculum entries flagged as provisional remain on the closed-beta editorial review list. Never silently upgrade an editorial draft to a professionally reviewed or source-verified historical case. For broad public availability, complete individual editorial QA, authenticated role tests, accessibility review, data provenance and historical replay licensing checks.
