# Admin Pre-LIVE Acceptance Center — v0.14.0.247

## Purpose
An Owner-only operational overview that reports current database configuration, safety switches, count evidence, and independently open payment/browser acceptance gates.

## Security
- GET only, role verified against the live Supabase Auth user endpoint and server-owned admin_user_roles records.
- Requires active OWNER role and member account; SHOWCASE_VIEWER always rejected, even if an additional OWNER role is erroneously assigned.
- Database secret and provider keys remain strictly server-side; only boolean configuration presence is returned.
- No mutations, live transactions, Sandbox transactions or automatic release approvals.
- Source unavailable -> action required/review, not verified.

## Owner workflow
Visit /admin.html, authenticate as genuine Owner and choose **Release & QA**. Select **Refresh evidence** to read current configuration. The view explicitly marks provider-delivered TEST Checkout, real browser acceptance, CI and LIVE payment authorization as independent open gates.

## Acceptance
- Unauthorized 401, incorrect methods 405, Showcase 403, expired Owner 403.
- Authorized GET with verified owner returns only safe aggregate counts and status checks.
- No secrets or real member personal information in response.
- Syntax and Node 22 source contract test in Deployment 16 workflow.
- Authenticated Owner UI and Cloudflare deployment require separate actual execution evidence.
